Setup

Как поднять эту документацию в GitBook через private GitHub repo:

  1. Создать private-репозиторий в GitHub.
  2. Залить содержимое этой папки в репозиторий.
  3. В GitBook создать private space.
  4. В space включить Git Sync и выбрать GitHub.
  5. Подключить созданный private repo.
  6. Проверить, что GitBook использует README.md, SUMMARY.md и .gitbook.yaml.

Официальные инструкции:

  • Git Sync
  • GitHub Sync
  • Content configuration
